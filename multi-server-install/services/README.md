# UnicChat Services

Канонический путь — один файл [`docker-compose.yml`](../docker-compose.yml). Какие блоки можно вынести на другой хост, написано комментариями в этом файле и в корневом [README.md](../../README.md) (п. 2.10–2.12).

YAML в этом каталоге (`mongodb.yml`, `appserver.yml` и остальные) — старые контуры. Для новых установок их не используйте.
