## Порядок для новой площадки

1. Прочитайте [требования](01-requirements.md) и выберите схему.
2. Согласуйте [сеть](04-network.md) и [TLS](05-tls.md).
3. Заполните `.env` и выполните `./validate-env.sh` — см. [проверку](07-validation.md).
4. Установите [один сервер](02-single-node.md) или [несколько](03-multi-node.md).
5. Пройдите критерии успеха в [проверке](07-validation.md).
6. Снимите первую резервную копию — [резервное копирование](08-backup-restore.md).
