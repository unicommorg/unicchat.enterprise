# Диагностика

Сначала посмотрите статус и последние строки лога роли, которая не `healthy`.

```shell
docker compose ps
docker compose logs --tail=100 <имя_контейнера>
```

## Установка

### DocumentServer долго не отвечает

**Причина.** Первые минуты идёт установка плагинов. Healthcheck `/healthcheck` становится зелёным раньше окончания.

**Что сделать.** Дождитесь в логе строки `Installing plugins, please wait...Done`. Сообщения MinIO `InsufficientWriteQuorum` в эту минуту сами по себе не означают отказ диска.

### Init пишет `already exists`

**Причина.** Повторный `up` снова запускает init-контейнеры.

**Что сделать.** Ничего, если рядом нет другой ошибки. Пользователи и секрет уже созданы.

### `validation FAILED` у `validate-env.sh`

**Причина.** Пустая переменная, `change_me_*` или `rs0key`.

**Что сделать.** Заполните `.env` по [секретам](06-secrets.md) и запустите скрипт снова.

## Несколько серверов

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| `Bind for 0.0.0.0:8080 failed` | порт занят | Logger публикуйте на 8082, Tasker на 8881, AppServer на 8080 |
| AppServer: `ECONNREFUSED ...:8080` к Tasker | в URL внутренний порт | `UNIC_SOLID_HOST=http://<tasker>:8881` |
| `KBTConfigs secret NOT created` | Vault не видит MongoDB или MinIO | поднимите их или поправьте `KBT_*`, затем снова `vault-init` |
| `KBTConfigs in Vault does not match .env` | секрет создан со старыми адресами | [пересоздайте секрет](06-secrets.md) и перезапустите Tasker |
| Nginx 502 на DocumentServer | в proxy нет порта | `DOCUMENT_SERVER_PROXY=<kb>:8880` |
| `Found orphan containers` | несколько compose-файлов в одном каталоге | предупреждение можно не трогать; `--remove-orphans` не используйте |

## TLS

### Браузер открывает сайт, мобильный клиент — нет

**Причина.** В `fullchain.pem` нет промежуточного сертификата, либо на телефонах нет корня внутреннего УЦ.

**Что сделать.** Допишите цепочку и проверьте модули ключа и сертификата, как в [TLS](05-tls.md).

### 502 от nginx

**Причина.** Upstream не слушает порт из `.env`.

**Что сделать.** С хоста Nginx: `curl -sv http://<UNICCHAT_HOST>:<NGINX_APP_PORT>/` (на одном сервере порт приложения внутри сети — 3000, с хоста опубликован 8080).
